## More Capable, Less Faithful: A Multilingual Analysis of Mathematical (Un)Solvability Detection in LLMs

## Dataset

The file **`MultilingualReliableDataset.zip`** contains the multilingual extension of the **ReliableMath** dataset introduced in our paper. It includes English (original), French, and Greek versions of both solvable and unsolvable mathematical problems.

Contents:

```
solve_english_original.json
solve_french.json
solve_greek.json
unsol_english_original.json
unsol_french.json
unsol_greek.json
```
